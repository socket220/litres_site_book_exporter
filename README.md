# Litres Site Book Exporter

Расширение Firefox для локального экспорта отображаемого текста и изображений из веб-читалки Литрес в EPUB. Версия **0.3.0**, Firefox **140+**.

## Возможности

- Ручной сбор и последовательное автоматическое перелистывание.
- Скорость: от 0,8 / 1,2 / 2,5 секунды на страницу; ожидание загрузки может увеличить паузу.
- Пауза и продолжение с текущей страницы.
- Сохранение прогресса локально, удаление повторов по идентификаторам блоков.
- Встраивание растровых изображений в PNG, оглавление и отчёт о пропусках.
- Остановка при ошибке изображения, зависшем переходе или изменении числа страниц.

Расширение работает с открытой авторизованной вкладкой. Оно не запрашивает внутренний API книги и не предоставляет доступ к недоступному пользователю контенту.

## Временная установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение…»**, выберите `manifest.json` из корня.
4. Обновите вкладку читалки и откройте панель дополнения.

Временная установка исчезает после перезапуска Firefox. Перед удалением или заменой расширения экспортируйте результат.

## Использование

Откройте книгу на `https://www.litres.ru/static/reader/text/`. Для полного прохода оставьте «Автосбор с первой страницы», выберите скорость и нажмите «Автосбор». Держите вкладку активной, не меняйте шрифт и размер окна.

Если программный переход к началу не сработает, перейдите к началу вручную и запустите сбор без этой галочки. Для продолжения после паузы также снимите галочку.

После прохода проверьте счётчики, отсутствующие заголовки и сообщения об ошибках. Нажмите «Сохранить EPUB». Файл можно отправить через [Send to Kindle](https://www.amazon.com/sendtokindle).

При обновлении исходников используйте «Перезагрузить» в `about:debugging`, затем обновите вкладку книги. ID расширения остаётся неизменным.

## Сборка ZIP / XPI

Нужен Python 3.9+; внешних зависимостей нет:

```sh
python scripts/package.py
```

В `dist/` появятся ZIP с исходниками и **неподписанный** XPI. Обычный Firefox требует подпись Mozilla для постоянной установки. Получение подписи без публикации в каталоге описано в [docs/INSTALL-XPI.md](docs/INSTALL-XPI.md).

## Проверки

Нужен Node.js 20+; дополнительных пакетов не требуется:

```sh
node --test tests/core.test.cjs
```

Тесты используют только синтетические данные. Они проверяют объединение блоков, конфликты, диагностику изображений и EPUB. [Подробности и границы проверки](docs/TESTING.md).

## Данные и разрешения

Текст, изображения и прогресс хранятся локально. Аналитики и серверов разработчика нет. Для изображений возможны HTTPS-запросы к `litres.ru`, `litres.com` и их поддоменам; браузер может приложить cookies сервиса. Скрипт сбора запускается только на странице читалки www.litres.ru.

Разрешения: `storage`, `downloads`, доступ к указанным доменам. В manifest объявлено использование `websiteContent` для запросов файлов изображений. Пароль в расширение вводить не нужно.

## Ограничения

- Полнота книги не гарантируется; отсутствие пропусков в оглавлении не доказывает наличие всего текста.
- Быстрый режим может быть менее надёжным при медленной загрузке без явного индикатора. При сомнении повторите осторожный проход.
- Автосбор требует активной вкладки; закрытие или обновление вкладки останавливает его.
- Поддерживаются растровые PNG/JPEG/GIF/WebP; анимация сохраняется одним кадром. SVG/аудио/видео не поддерживаются.
- Входное изображение ограничено 10 МБ, преобразование — 24 миллионами пикселей.
- Изменение разметки сайта может потребовать обновления расширения.
- Подписание Mozilla, установка версии 0.3 в живой Firefox и доставка на Kindle не проверены в автоматических тестах.

## Структура

`core.js` — разбор и объединение блоков; `content.js` — сбор и перелистывание; `background.js` — хранилище, изображения и экспорт; `epub.js` — EPUB/ZIP; `popup.*` — панель управления.
