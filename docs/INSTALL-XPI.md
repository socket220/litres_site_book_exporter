# Постоянная установка XPI

После выполнения `python scripts/package.py` файл dist/litres-epub-v0.3.0-unsigned.xpi — пакет расширения, **пока без подписи Mozilla**. В обычном Firefox его нельзя установить постоянно через about:addons до подписи. Переименование ZIP в XPI не заменяет подпись.

## Получить подпись без публикации в каталоге

1. Войдите в https://addons.mozilla.org/developers/ под своей учётной записью Mozilla.
2. Выберите Submit a New Add-on. Для собственного распространения выберите **On your own**, а не публикацию в каталоге.
3. Загрузите litres-epub-v0.3.0-unsigned.xpi.
4. Дождитесь проверки и исправьте ошибки валидатора, если они будут. Пакет не проверялся валидатором AMO, одобрение не гарантируется.
5. В пакете находятся читаемые исходники JavaScript без сборки, минификации и внешних библиотек. Если система спрашивает о дополнительном исходном коде для сборки, отдельной сборки здесь нет.
6. После подписи скачайте именно подписанную версию из списка версий дополнения.
7. В Firefox откройте about:addons → шестерёнка → **Установить дополнение из файла…** → выберите подписанный XPI.
8. Обновите вкладку читалки. Подписанная установленная версия сохраняется после перезапуска Firefox.

Перед заменой временного дополнения сохраните EPUB. ID остаётся local-reader-epub@example.invalid. Перенос данных при замене временной установки на постоянную не проверен. При необходимости повторите сбор.

Обновления тоже требуют подписи. Автоматическая раздача обновлений не настроена; новые подписанные XPI устанавливаются вручную с тем же ID и более высокой версией.

## Данные и доступ

Для подписи в manifest добавлено объявление websiteContent: расширение обращается к доменам Литрес за файлами отображаемых изображений, браузер может приложить cookies этого сервиса. Текст книги, отчёты и изображения хранятся локально. Нет аналитики, аккаунта расширения, серверов разработчика или передачи книг посторонним сервисам. Минимальная версия Firefox — 140.

Описание функции для проверки: локальный экспорт отображаемого содержимого читалки в EPUB; автоматизация штатной кнопки следующей страницы; получение изображений только по адресам из отображаемого HTML, только с HTTPS-доменов Литрес. Внутренние API книги не запрашиваются. Обхода механизмов доступа нет.

## Временная установка

Можно использовать распакованную папку с manifest.json через about:debugging. Подпись для временной отладки не требуется, но такая установка исчезает после перезапуска.
